# 見本のテスト（中学2年 数学 2学期中間テスト・一次関数）

この講座の第3回〜第5回で、実際にCodexに作らせた見本です。

- `hani.txt` … Codexに渡した範囲メモ（第2回）
- `中2数学_2学期中間テスト_問題用紙_修正版.docx` … 直しと検算を通したあとの問題用紙（第4回・第5回）
- `中2数学_2学期中間テスト_解答用紙_修正版.docx` … 同じく解答用紙
- `中2数学_2学期中間テスト_模範解答と配点表_修正版.docx` … 同じく模範解答と配点表
- `01_最初にできた版/` … 第3回で最初にできた3つ（直す前の状態）

問題はCodexが数値を決めて作った自作のものです。中学2年の一次関数の範囲なら、自分のクラス用に直して使ってかまいません。配る前に、全問を自分で解いて確かめてください。
