# Codexで作る 中学校の定期テスト

中学校の先生に向けた、全5回の無料Web講座です。OpenAIのCodexに範囲メモ1枚を渡し、中間テスト・期末テストの問題用紙・解答用紙・模範解答をWordファイルで作らせ、先生が全問解いて確かめてから配る手順を紹介しています。

- 第1回 定期テストのどこをCodexに任せるか
- 第2回 準備 Codexと範囲メモ
- 第3回 範囲メモから作らせる
- 第4回 直す 整える 印刷する
- 第5回 配る前に守る3つ
- 番外編 保健の期末テストと指導要領の根拠（体育科の先生からの相談で作った回。各問題に学習指導要領の該当箇所を明記させる型）

`sample/` には、第3回で実際にCodexに作らせた見本（中学2年 数学 2学期中間テスト・一次関数）の3点セットと、番外編の見本（中学2年 保健分野 2学期期末テスト・指導要領対応表つき）を置いています。
